- 複数パスの履歴とレビューに使う安定 URL scheme として、`/s/:stash/commits`、
  `/s/:stash/commits/:id`、`/s/:stash/change-sets`、`/s/:stash/change-sets/:id` を追加しました。
- 必須の `commitId` で change row をまとめ、上限付きの entry ごとの diff を表示し、書き込み可能な
  principal に atomic revert と change-set decision flow を提供します。
