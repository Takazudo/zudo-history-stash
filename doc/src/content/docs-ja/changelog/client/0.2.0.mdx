Released: 2026-08-29

- fetch と named RPC transport に `commits(stash)`、`changeSets(stash)`、
  `files(stash).snapshot()` API を追加しました。
- atomic な `conflicts[]` を `404 not-found` と `409 commit-conflict` の両方で維持し、
  `isCommitConflict` guard を `409 commit-conflict` branch 専用として追加しました。複数パスの stale を
  自動再試行することはありません。
- version、history、change-feed、live-event の型で `commitId` を必須にし、fake と conformance surface でも
  all-or-none behavior を維持しました。
