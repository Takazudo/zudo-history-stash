リリース日: 2026-08-25

- Node.js、ブラウザー、および Cloudflare Worker の service binding で利用できる isomorphic な `createStashClient`
  API を追加しました。
- 管理者、token、import、file、history、change-feed、stored-diff、および candidate-diff の各ルートに、型付きのビジネス結果で
  対応しました。
- representation cache の処理、自動的な idempotency key、replay メタデータ、および回数制限付きの `putLatest`
  競合リトライを追加しました。
- capability に基づく binary/large-object upload、current/history の stream download、再開可能な
  session 操作、上限付き materializer、観測 progress、および Request/Response RPC stream の
  flow control を追加しました。
