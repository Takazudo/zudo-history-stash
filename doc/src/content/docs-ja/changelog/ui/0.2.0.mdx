- commit の list/detail、atomic revert、change-set の list/review、approve/reject の UI workflow を
  追加しました。
- commit/change-set の route kind と commit badge を追加し、必須の `commitId` が同じ連続 change row を
  一つにまとめて表示します。
- 助言的な `commit`/`change-set` live frame から複数パス view を更新しつつ、正本 resource との照合を
  維持します。
