## 非推奨化ポリシー

現時点では、固定の非推奨期間を保証していません。破壊的変更を含むリリースは、リリースツールの
`!` または `BREAKING CHANGE` 規約を使用し、パッケージの変更履歴で内容を説明する必要があります。
利用側では互換性のあるバージョンを固定してください。
