### `POST /v1/stashes/{stash}/proposals`

**Contract:** operation `createProposal`; principal `write`; transport `any`.

任意の有効期限と冪等性キーを指定して、不変の候補 `{ path, body, baseVersion, ... }` を作成し、`201` を
返します。`baseVersion: null` はパスが存在してはならないことを意味します。`meta.proposalId` はサーバーが
所有します。同じ key/request を replay すると元の record を返します。そのキーで内容を変えると
`422 idempotency-key-reused` です。

### `GET /v1/stashes/{stash}/proposals`

**Contract:** operation `listProposals`; principal `read`; transport `any`.

status と任意の完全一致 path によって proposal を絞り込み、上限付き `limit` と opaque `after` を使って
新しい順に一覧表示します。`total` は返された page だけでなく、絞り込まれた集合全体を表します。

### `GET /v1/stashes/{stash}/proposals/{id}`

**Contract:** operation `getProposal`; principal `read`; transport `any`.

proposal record と、その不変の候補 body を返します。未知の proposal や他者の proposal は開示しません。

### `GET /v1/stashes/{stash}/proposals/{id}/diff`

**Contract:** operation `getProposalDiff`; principal `read`; transport `any`.

不変の base/candidate side と、別に変化する current-head/stale field を含む候補 diff を返します。任意の
負でない `context` が周辺行を制御します。

### `POST /v1/stashes/{stash}/proposals/{id}/approve`

**Contract:** operation `approveProposal`; principal `write`; transport `any`.

現在の head が proposal base と正確に一致する場合だけ適用します。任意の author/message 値は、適用される
version に保存済みの値を上書きします。stale な head は `409 stale` です。有効期限と終端判断には、それぞれ
専用の `409` code があります。適用済み proposal をもう一度承認すると、version を追加せずに同じ結果を
再構成します。

### `POST /v1/stashes/{stash}/proposals/{id}/reject`

**Contract:** operation `rejectProposal`; principal `write`; transport `any`.

任意の上限付き reason を記録し、reject 済み record を返します。rejection は冪等で、有効期限を過ぎた
open proposal を閉じることもできますが、適用済みの判断を置き換えることはできません。
