### `GET /v1/health`

**Contract:** operation `health`; principal `open`; transport `any`.

認証情報、body、query は不要です。正常な service は `200` とともに `ok: true`、service 名、安定した
health marker を返します。network または infrastructure の失敗は route レベルの業務エラー契約の
範囲外です。

### `GET /v1/capabilities`

**Contract:** operation `getCapabilities`; principal `open`; transport `fetch-only`.

デプロイ済みの transfer と storage の capabilities、および raw single と multipart upload の正確な byte
設定を返します。クライアントは platform plan を推測したり、サイズの閾値を representation の判断に使ったりせず、
この response から transfer mode を選択してください。

### `GET /v1/me`

**Contract:** operation `me`; principal `any`; transport `any`.

admin principal、または認証済み stash principal の情報（stash、token ID、scope、有効期限）を `200` で
返します。無効な認証情報では `401`、read 分類の throttling では `429` とともに `Retry-After` を返します。
