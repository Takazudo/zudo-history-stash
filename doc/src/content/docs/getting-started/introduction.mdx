## What is Doc?

This temporary page records that the site uses
[zudo-doc](https://github.com/zudolab/zudo-doc), a minimal documentation framework powered by zfb,
MDX, and Tailwind CSS. It will be replaced by the product introduction in the next content wave.

## Key Features

- MDX authoring with rich component support
- Fast static site generation via zfb
- Tailwind CSS v4 for styling
- Optional i18n, search, and more
