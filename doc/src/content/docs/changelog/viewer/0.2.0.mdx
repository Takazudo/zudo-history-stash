- Add `/s/:stash/commits`, `/s/:stash/commits/:id`, `/s/:stash/change-sets`, and
  `/s/:stash/change-sets/:id` as the stable URL scheme for multi-path history and review.
- Group change rows by required `commitId`, expose bounded per-entry diffs, and provide atomic
  revert and change-set decision flows to write-capable principals.
