### `GET /v1/health`

**Contract:** operation `health`; principal `open`; transport `any`.

No credential, body, or query is required. A healthy service returns `200` with `ok: true`, the
service name, and the stable health marker. Network or infrastructure failure is outside the
route-level business-error contract.

### `GET /v1/capabilities`

**Contract:** operation `getCapabilities`; principal `open`; transport `fetch-only`.

Returns the deployment's transfer and storage capabilities, including exact byte settings for raw
single and multipart uploads. Clients should select a transfer mode from this response rather than
assuming a platform plan or treating a size threshold as a representation decision.

### `GET /v1/me`

**Contract:** operation `me`; principal `any`; transport `any`.

Returns `200` with either the admin principal or the authenticated stash, token ID, scope, and
expiry. Invalid credentials return `401`; read-class throttling returns `429` with `Retry-After`.
