# Changelog

All notable changes to `@takazudo/zudo-history-stash-ui` are documented in this file.

The format is based on Keep a Changelog, and release notes are generated from the changelog MDX pages.

## [0.2.0]

- Add commit list/detail, atomic revert, change-set list/review, and approve/reject UI workflows.
- Add commit and change-set route kinds, commit badges, and folding for consecutive change rows with
  the same required `commitId`.
- Refresh multi-path views from advisory `commit` and `change-set` live frames while continuing to
  reconcile authoritative resources.

## [0.1.0]

- Add the embeddable provider, capability hooks, link bridge, base primitives, and namespaced CSS
  surface.
